Boklogg: bokarkiv

Om prosjektet:
Boklogg er en enkel webside for å registrere og holde oversikt over egne bøker. Applikasjonen gjør det mulig å organisere bøker, følge lesestatus og se egen lesefremdrift.

Funksjonalitet:
Applikasjonen har følgende funksjoner:
Legge til bøker: Registrere tittel, forfatter, antall sider, sjanger og lesestatus.
Redigere bøker: Oppdatere informasjon om eksisterende bøker.
Slette bøker: Fjerne bøker fra bokarkivet med bekreftelse.
Søke:Søke etter bøker basert på tittel eller forfatter.
Filtrere: Filtrere boklisten etter sjanger og lesestatus.
Sortere:Sortere bøker alfabetisk etter tittel eller etter antall sider.
Lesestatistikk: Vise oversikt over totalt antall bøker, leste bøker og bøker som leses nå.
Lokal lagring: Bøkene lagres i nettleserens LocalStorage.

Hvordan bruke applikasjonen
Legg til en bok ved å fylle ut skjemaet.
Bruk søkefeltet for å finne bøker.
Bruk filtrene for å vise bøker etter sjanger eller status.
Sorter boklisten etter tittel eller antall sider.
Rediger eller slett bøker ved hjelp av knappene i boklisten.
